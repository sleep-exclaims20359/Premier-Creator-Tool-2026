## FAQ

### What does VideoPatch actually do?

VideoPatch applies a patch to supported video editing software to unlock their premium features, remove watermarks, and activate tools that are otherwise restricted to paid versions.

### Is this safe to use on my computer?

VideoPatch is designed as a standalone tool and does not install background services. However, as with any software modification tool, you should always download it from trusted sources and run a security scan.

### Which versions of the video editors are supported?

VideoPatch is regularly updated to support the latest stable releases of CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi Video Suite.

### Do I need an internet connection to use it?

No, VideoPatch works entirely offline. The activation is applied locally to the software files on your system.

### Will this affect future updates of the video editors?

Major updates from the software vendors may reset the activation. You may need to re-run VideoPatch after a significant version update of the editor.

### Can I use VideoPatch on a Mac or Linux system?

No, VideoPatch is a Windows-only desktop application (.exe) and is designed to patch Windows installations of the supported video editors.

### The patch failed. What should I do?

Ensure the target video editor is completely closed, run VideoPatch as an administrator, and check that you have the correct version. Temporarily disable anticomponent software that might interfere, and consult the GitHub issues page for help.
